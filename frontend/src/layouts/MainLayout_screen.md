# MainLayout_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/layouts/MainLayout.vue
- **화면 이름**: 공통 레이아웃
- **화면 목적**: 회원 화면의 공통 틀. 개인·팀 공간을 고르고 메뉴 탭으로 화면을 옮기며, 알림을 보고 로그아웃한다
- **접근 URL**: /personal/tasks, /personal/calendar, /personal/history, /teams/{팀 id}/tasks, /teams/{팀 id}/calendar, /teams/{팀 id}/info, /teams/{팀 id}/history, /profile (회원정보 수정, 메뉴 탭 숨김). `/` 는 /personal/tasks 로. 없는 주소는 로그인했으면 /personal/tasks, 아니면 /login (D-119)
- **접근 권한**: 회원 (비회원이 오면 로그인 화면으로 보낸다, D-051)
- **시안 파일 경로**: 프로젝트/docs/mockups/main_layout.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 알림 종 | 클릭 | 알림 창 열기/닫기. 회원 메뉴가 열려 있으면 닫는다. 열 때 GET /api/notifications 로 목록을 다시 불러오고, 안 본 알림이 있으면 POST /api/notifications/read → 배지 숨김 (D-096) |
| 안 본 알림 개수 | 화면 열기, 화면 이동(경로 바뀜) | GET /api/notifications 로 배지 개수를 다시 불러온다 |
| 초대 [수락] | 클릭 | POST /api/notifications/{id}/accept → 알림 항목 빼기, 팀 목록 맨 위에 그 팀 추가. "{팀 이름} 팀에 가입했습니다." 안내 토스트 (화면은 옮기지 않는다). 409 TEAM_LIMIT_EXCEEDED 면 "가입된 팀이 20개라 더 가입할 수 없습니다." 오류 토스트 (알림은 남는다). 404 면 "이미 없어진 초대입니다." 오류 토스트 + 목록 다시 불러오기 |
| 초대 [거절] | 클릭 | POST /api/notifications/{id}/decline → 알림 항목 빼기 (확인창 없음). 404 면 목록 다시 불러오기 |
| 작업자 지정·마감 임박 알림 | 항목 클릭 | 알림 창 닫고 그 작업 화면으로 이동해 상세 UI 를 연다: 팀 작업이면 /teams/{팀 id}/tasks?taskId={작업 id}, 개인 작업이면 /personal/tasks?taskId={작업 id} (TaskView 가 처리). 알림은 지우지 않는다 |
| 알림 [X] | 클릭 | POST /api/notifications/{id}/delete → 항목 빼기 (확인창 없음). 404 면 목록 다시 불러오기 |
| 회원정보 수정 | 클릭 | 회원 메뉴 닫고 /profile 로 이동 (D-053) |
| 팀 목록 항목 | 드래그해서 놓기 | 놓은 자리로 바로 옮기고 POST /api/teams/{id}/move (index) → 서버가 준 순서로 다시 그린다. 실패하면 원래 순서로 되돌리고 오류 토스트. 클릭과 구분하려고 5px 이상 움직여야 드래그로 본다 |
| 회원(닉네임·이메일) | 클릭 | 회원 메뉴 열기/닫기. 알림 창이 열려 있으면 닫는다 |
| 알림 창·회원 메뉴 | 바깥 클릭 또는 Esc | 닫는다 |
| 로그아웃 | 클릭 | API → /login 이동. 실패하면 오류 토스트 |
| 개인 | 클릭 | /personal/tasks 로 이동 |
| 팀 목록 항목 | 클릭 | 그 팀의 작업 탭(/teams/{팀 id}/tasks)으로 이동. 메뉴 탭이 팀 공간 탭(작업 / 캘린더 / 팀 정보 / 히스토리)으로 바뀐다 |
| 팀 만들기 [+] | 클릭 | 팀 만들기 모달 열기 (D-073). aria-label "팀 만들기" |
| 모달 [만들기] | 클릭 또는 Enter | 입력 검사(빈 값 "팀 이름을 입력해 주세요.", 20자 초과 "팀 이름은 20자 이하로 입력해 주세요.") → POST /api/teams → 모달 닫기, 팀 목록 맨 위에 추가 (D-089), 그 팀의 팀 정보 탭(/teams/{팀 id}/info)으로 이동 (D-073). 409 TEAM_LIMIT_EXCEEDED 면 입력칸 아래 "가입된 팀이 20개라 더 만들 수 없습니다." |
| 모달 [취소] | 클릭, 바깥 클릭, Esc | 입력을 버리고 닫는다 |
| 실시간 연결 | 로그인한 화면이 열림 | Socket.IO 연결 (api.md 6.8). 로그아웃하면 끊는다. 다시 연결되면 안 본 알림 개수와 팀 목록을 다시 불러온다 |
| notifications:changed | 받음 | 배지 개수를 unreadCount 로 바꾼다. 알림 창이 열려 있으면 목록을 다시 불러오고 POST /api/notifications/read (D-096) |
| teams:changed (joined / left) | 받음 | 팀 목록 다시 불러오기 (다른 탭에서 한 일) |
| teams:changed (removed / dissolved) | 받음 | 팀 목록 다시 불러오기. 그 팀 공간을 보고 있으면 열린 모달·확인창을 닫고 /personal/tasks 로 이동 + 오류 토스트 "팀에서 내보내졌습니다." / "팀이 해체되었습니다." (D-104). 보고 있지 않으면 토스트 없이 목록만 바꾼다 |
| 팀 경로 열기 | 내가 속하지 않은 팀 id 로 들어옴 (404) | "팀을 찾을 수 없습니다." 오류 토스트 + 팀 목록 새로고침 + /personal/tasks 로 이동 |
| 메뉴 탭 | 클릭 | 해당 경로로 이동, 선택 탭 녹색 |
| 화면 열기 | 비회원이 들어옴 | 로그인 화면으로 이동 (D-051) |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | /api/sessions/me | 로그인 확인, 닉네임·이메일 표시 |
| POST | /api/sessions/logout | 로그아웃 |
| GET | /api/teams | 내 팀 목록 (좌측 네비) |
| POST | /api/teams | 팀 만들기 |
| POST | /api/teams/{id}/move | 팀 목록 드래그 순서 변경 (D-089) |
| GET | /api/notifications | 알림 목록, 안 본 알림 개수 (마감 임박 알림도 이때 만들어진다, D-128) |
| POST | /api/notifications/{id}/delete | 작업자 지정·마감 임박 알림 지우기 |
| Socket.IO | notifications:changed, teams:changed | 실시간 배지·팀 목록 (api.md 6.8) |
| POST | /api/notifications/read | 알림 모두 본 것으로 |
| POST | /api/notifications/{id}/accept | 초대 수락 |
| POST | /api/notifications/{id}/decline | 초대 거절 |

### 사용 테이블
- users, login_tokens, teams, team_members, notifications

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 (작업 탭) | "개인" 선택, 작업 탭 녹색 |
| 팀 공간 | 팀 목록에서 그 팀 선택 표시, 메뉴 탭 작업 / 캘린더 / 팀 정보 / 히스토리 |

| 회원정보 수정 화면 | 네비에서 개인·팀 어느 것도 선택 표시 없음, 메뉴 탭 숨김 |

| 회원 메뉴 열림 | 닉네임·이메일 위 작은 메뉴 |
| 긴 닉네임·이메일 | 한 줄에서 … 로 줄임 |
| 로딩 중 | [로그아웃] 안 스피너 + "로그아웃 중...", 비활성 |
| 오류 | 서버 오류 토스트 |
