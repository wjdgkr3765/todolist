# MainLayout_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/layouts/MainLayout.vue
- **화면 이름**: 공통 레이아웃
- **화면 목적**: 회원 화면의 공통 틀. 개인·팀 공간을 고르고 메뉴 탭으로 화면을 옮기며, 알림을 보고 로그아웃한다
- **접근 URL**: /personal/tasks, /personal/calendar, /personal/history, 팀 경로 /teams/{팀 id}/.... `/` 는 /personal/tasks 로
- **접근 권한**: 회원 (비회원이 오면 로그인 화면으로 보낸다, D-051)
- **시안 파일 경로**: 프로젝트/docs/mockups/main_layout.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 알림 종 | 클릭 | 알림 창 열기/닫기. 회원 메뉴가 열려 있으면 닫는다 |
| 회원(닉네임·이메일) | 클릭 | 회원 메뉴 열기/닫기. 알림 창이 열려 있으면 닫는다 |
| 알림 창·회원 메뉴 | 바깥 클릭 또는 Esc | 닫는다 |
| 로그아웃 | 클릭 | API → /login 이동. 실패하면 오류 토스트 |
| 개인 | 클릭 | /personal/tasks 로 이동 |
| 팀 목록 항목 | 클릭 | 그 팀 공간(/teams/{팀 id}/...)으로 이동 (팀 생성/관리 작업에서 설계) |
| 팀 만들기 [+] | 클릭 | 가운데 모달에서 팀 이름 입력. 만들면 그 팀의 팀 정보 탭으로 이동 (D-073, 팀 생성/관리 작업에서 설계) |
| 메뉴 탭 | 클릭 | 해당 경로로 이동, 선택 탭 녹색 |
| 화면 열기 | 비회원이 들어옴 | 로그인 화면으로 이동 (D-051) |
