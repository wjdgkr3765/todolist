# LoginView_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/views/LoginView.vue
- **화면 이름**: 로그인
- **화면 목적**: 비회원이 아이디와 비밀번호로 로그인한다. 회원가입·아이디 찾기·비밀번호 찾기로 이동한다
- **접근 URL**: /login
- **접근 권한**: 비회원 (로그인한 회원이 오면 로그인 후 화면으로 보낸다, D-051)
- **시안 파일 경로**: 프로젝트/docs/mockups/login_view.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 2. 레이아웃

회원가입 화면과 같은 틀(배경, 2단 카드, AuthBrandPanel, 반응형)을 쓴다.

| 영역 | 위치 | 내용 |
|---|---|---|
| 배경 / 카드 / 브랜드 영역 | 회원가입과 같음 | SignupView_screen.md "2. 레이아웃"과 같음 (AuthBrandPanel) |
| 폼 제목 | 폼 영역 위쪽 | "로그인" + 안내 "아이디와 비밀번호를 입력해 주세요." |
| 입력 | 폼 제목 아래 | 아이디, 비밀번호 |
| 오류 상자 | 비밀번호 아래 | 로그인 실패·잠금 문구 (빨강 연한 배경 상자). 실패했을 때만 |
| 로그인 버튼 | 입력 아래 | [로그인] (가로 꽉 차게, 그라데이션) |
| 찾기 링크 | 로그인 버튼 아래 가운데 | "아이디 찾기 · 비밀번호 찾기" |
| 하단 링크 | 맨 아래 | "아직 계정이 없으신가요? 회원가입" |
| 알림 | 화면 위쪽 가운데 | 오류 토스트 |

### 반응형 기준
- 회원가입 화면과 같다 (SignupView_screen.md "반응형 기준")

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 아이디 | 입력칸 | placeholder "아이디", 왼쪽 아이콘 bi-person | 사용자 입력 | maxlength 15, 앞뒤 공백 제거, autocomplete username |
| 비밀번호 | 입력칸(password) | placeholder "비밀번호", 왼쪽 아이콘 bi-lock | 사용자 입력 | maxlength 15, autocomplete current-password |
| 비밀번호 보기 | 아이콘 버튼 | bi-eye / bi-eye-slash | - | 비밀번호 칸 오른쪽 |
| 입력 오류 | 텍스트 | "아이디를 입력해 주세요." / "비밀번호를 입력해 주세요." | 화면 검사 | 해당 칸 아래 빨강 |
| 오류 상자 | 상자 | 실패: "아이디 또는 비밀번호가 올바르지 않습니다." / 잠금: 서버 문구 "비밀번호를 5번 틀려 로그인이 잠겼습니다. N분 뒤 다시 시도해 주세요." | POST /api/sessions 오류 응답 | 아이콘 bi-exclamation-circle |
| 로그인 | 버튼 | 로그인 | POST /api/sessions | 가로 꽉 차게, 그라데이션 |
| 찾기 링크 | 링크 | 아이디 찾기 (/find-id), 비밀번호 찾기 (/find-password) | - | |
| 회원가입 | 링크 | 회원가입 (/signup) | - | |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 아이디 / 비밀번호 | 입력 | 그 칸의 입력 오류와 오류 상자를 지운다 |
| 로그인 | 클릭 또는 Enter | 빈 칸이 있으면 해당 칸 아래 오류 + 첫 빈 칸으로 이동. 아니면 API → 성공: 로그인 후 화면(/personal/tasks)으로 이동. LOGIN_FAILED: 오류 상자 + 비밀번호 칸 비우고 이동. LOGIN_LOCKED: 오류 상자에 서버 문구. 그 밖의 오류: 오류 토스트 |
| 아이디 찾기 / 비밀번호 찾기 | 클릭 | /find-id, /find-password 로 이동 |
| 회원가입 | 클릭 | /signup 으로 이동 |
| 화면 열기 | 로그인한 회원이 들어옴 | GET /api/sessions/me 로 확인해 로그인 후 화면으로 이동 (D-051) |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 | 빈 아이디·비밀번호 칸, 오류 상자 없음 |
| 입력 오류 | 빈 칸 빨강 테두리 + 칸 아래 빨강 문구 |
| 로그인 실패 | 오류 상자 "아이디 또는 비밀번호가 올바르지 않습니다.", 비밀번호 칸 비움 |
| 로그인 잠김 | 오류 상자 "비밀번호를 5번 틀려 로그인이 잠겼습니다. N분 뒤 다시 시도해 주세요." |
| 로딩 중 | [로그인] 안 스피너 + "로그인 중...", 비활성 |
| 오류 | 서버 오류 토스트 |
