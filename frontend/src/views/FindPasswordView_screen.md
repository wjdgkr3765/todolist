# FindPasswordView_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/views/FindPasswordView.vue
- **화면 이름**: 비밀번호 찾기
- **화면 목적**: 비회원이 아이디와 이메일로 인증번호를 받아 본인을 확인하고 새 비밀번호를 정한다 (D-020, D-115, D-116)
- **접근 URL**: /find-password
- **접근 권한**: 비회원 (로그인한 회원이 오면 로그인 후 화면 /personal/tasks 로 보낸다, D-051 과 같음)
- **시안 파일 경로**: 프로젝트/docs/mockups/find_password_view.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 아이디 | 입력칸 (bi-person) | placeholder "아이디" | 사용자 입력 | maxlength 15, 형식 검사 없이 빈 값만 확인 (로그인과 같음) |
| 이메일 | 입력칸(email) (bi-envelope) | placeholder "example@email.com" | 사용자 입력 | maxlength 100 |
| 인증번호 발송 | 버튼 | 인증번호 발송 → 재발송 | POST /api/email-verifications (purpose = find_password, loginId 포함) | 회원가입과 같음 |
| 인증번호 / 남은 시간 / 확인 | 입력칸·배지·버튼 | 회원가입과 같음 | POST /api/email-verifications/{id}/verify | |
| 인증 완료 표시 | 배지 + [변경] | 아이디·이메일 칸 회색 잠금 + 이메일 칸 안 초록 인증 배지 + [변경] | - | 회원가입 D-039 와 같은 모양 |
| 새 비밀번호 | 입력칸(password) (bi-lock) + 보기 버튼 | placeholder "영어, 숫자, 특수문자를 모두 포함 8~15자" | 사용자 입력 | maxlength 15, 인증을 마친 뒤에만 보임 |
| 새 비밀번호 확인 | 입력칸(password) (bi-shield-lock) | placeholder "새 비밀번호를 한 번 더 입력" | 사용자 입력 | 서버로 보내지 않음 |
| 남은 변경 시간 | 안내 문구 | "인증 후 30분 안에 변경해 주세요." | 고정 | 새 비밀번호 구역 제목 아래 (D-116) |
| 비밀번호 변경 | 버튼 | 비밀번호 변경 | POST /api/users/reset-password | 회원가입 [가입하기] 와 같은 모양 |
| 로그인으로 돌아가기 | 링크 | 로그인으로 돌아가기 | - | /login |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 열기 | 아이디 찾기에서 넘어옴 | 아이디·이메일 칸을 채워 둔다 |
| 인증번호 발송 | 클릭 | 아이디 빈 값 "아이디를 입력해 주세요.", 이메일 형식 오류는 칸 아래. 맞으면 API: 404 ACCOUNT_NOT_FOUND 면 이메일 칸 아래 "아이디와 이메일이 일치하는 회원이 없습니다." (D-117). 성공하면 회원가입과 같음 |
| 아이디 / 이메일 | 발송 후 수정 | 인증번호 칸을 숨기고 처음부터 다시 발송 |
| 확인 | 클릭 | 틀림·만료·무효는 회원가입과 같음. 맞으면 "인증되었습니다." + 아이디·이메일 잠금 + 새 비밀번호 구역 표시, 새 비밀번호 칸에 포커스 |
| [변경] | 클릭 | 인증 취소, 새 비밀번호 구역 숨김, 아이디·이메일 칸 다시 입력 가능 |
| 새 비밀번호 / 확인 | blur | 형식 오류·불일치 검사와 문구는 회원가입의 비밀번호 / 비밀번호 확인과 같다 |
| 비밀번호 변경 | 클릭 | 화면 검사 → API → 성공: 모든 입력칸·버튼 잠금 + 안내 토스트 "비밀번호를 바꿨습니다. / 새 비밀번호로 로그인해 주세요." + 1.5초 뒤 /login 이동 (D-116). 400 EMAIL_NOT_VERIFIED(30분 지남) 면 "인증 시간이 지났습니다. 다시 인증해 주세요." + 본인 확인 구역을 처음 상태로. 404 ACCOUNT_NOT_FOUND(그사이 탈퇴) 면 오류 토스트 + 처음 상태로 |
| 로그인으로 돌아가기 | 클릭 | /login |
| 모든 API | 500 등 | 서버 오류 토스트 (MAIL_SEND_FAILED 면 "메일을 보내지 못했습니다. 잠시 후 다시 시도해 주세요.") |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| POST | /api/email-verifications | 인증번호 발송 (purpose = find_password) |
| POST | /api/email-verifications/{id}/verify | 인증번호 확인 |
| POST | /api/users/reset-password | 비밀번호 재설정 |

### 사용 테이블
- users, email_verifications, login_tokens

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 | 아이디, 이메일 + [인증번호 발송], 인증번호 칸·새 비밀번호 구역 숨김 |
| 일치하는 회원 없음 | 이메일 칸 빨강 테두리 + "아이디와 이메일이 일치하는 회원이 없습니다." |
| 인증번호 발송 후 / 틀림 / 만료 / 무효 | 회원가입과 같음 |
| 인증 완료 | 아이디·이메일 잠금 + 인증 배지 + [변경], 새 비밀번호 구역 표시 |
| 새 비밀번호 입력 오류 | 칸 빨강 테두리 + 문구 |
| 로딩 중 | 누른 버튼 안 스피너, 비활성 ([비밀번호 변경]은 "변경 중...") |
| 변경 완료 | 안내 토스트, 모든 입력칸 회색 잠금, 모든 버튼 비활성 |
| 오류 | 서버 오류 토스트 |
