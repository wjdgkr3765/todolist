# TeamInfoView_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/views/TeamInfoView.vue
- **화면 이름**: 팀 정보
- **화면 목적**: 팀원이 팀 정보와 팀원 목록을 보고, 다른 회원을 초대하며, 권한에 따라 팀 이름 수정, 역할 부여, 관리자 넘기기, 팀원 내보내기, 팀 탈퇴, 팀 해체를 한다 (D-074, D-081, D-091)
- **접근 URL**: /teams/{팀 id}/info
- **접근 권한**: 팀원 (그 팀에 속한 회원). 버튼은 역할에 따라 보인다 (api.md 6.6 권한 표)
- **시안 파일 경로**: 프로젝트/docs/mockups/team_info_view.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 2. 레이아웃

공통 레이아웃(MainLayout)의 내용 영역 안에 들어간다. 위에서 아래로 쌓는다 (D-081).

| 영역 | 위치 | 내용 |
|---|---|---|
| 팀 정보 카드 | 맨 위 | 팀 이름, 관리자 닉네임, 팀원 수, 만든 날짜, [이름 수정] |
| 팀원 게시판 | 가운데 | 제목 "팀원 (N명)" + 같은 줄 오른쪽 [초대] (D-091) + 팀원 목록 표 (닉네임, 이메일, 역할 배지, 합류일, [⋮]) |
| 답을 기다리는 초대 | 팀원 게시판 아래 (D-120) | 제목 "답을 기다리는 초대 (N)" + 목록 (닉네임, 이메일, 초대한 사람, 초대일, [취소]). 없으면 이 영역을 숨긴다 |
| 팀 해체 / 팀 탈퇴 버튼 | 맨 아래, 폭 100% | 관리자: 빨간 [팀 해체] / 부관리자·팀원: 빨간 테두리 [팀 탈퇴] |
| 확인창·모달 | 화면 가운데 (어두운 배경 위) | 초대 모달, 관리자 넘기기, 내보내기, 팀 탈퇴, 팀 해체(이름 입력 → 최종 확인) |
| 알림(토스트) | 화면 위쪽 가운데 | 안내(초록 띠) / 오류(빨강 띠) |

### 반응형 기준
- 내용 영역 최소 폭 320px 을 따른다 (MainLayout_screen.md)
- 768px 미만: 팀원 표의 이메일 열을 숨기고 닉네임 아래에 작은 글씨로 보여준다
- 내용 최대 폭 880px, 가운데 정렬 없이 왼쪽 정렬

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 열기 | 들어옴 | GET /api/teams/{id}, GET /api/teams/{id}/members, GET /api/teams/{id}/invitations 를 함께 불러온다. 404 면 "팀을 찾을 수 없습니다." 오류 토스트 + 내 팀 목록 새로고침 + /personal/tasks 로 이동 |
| [초대] | 클릭 | 초대 모달 열기 |
| 초대 모달 [초대] | 클릭 또는 Enter | 입력 검사(빈 값 "이메일을 입력해 주세요.", 형식 "이메일 형식이 올바르지 않습니다.") → POST /api/teams/{id}/invitations → 모달 닫기 + "초대했습니다." 안내 토스트. isMailSent 가 false 면 "초대했지만 안내 메일은 보내지 못했습니다." 안내 토스트. 404 USER_NOT_FOUND "가입된 회원이 아닙니다." / 409 ALREADY_TEAM_MEMBER "이미 팀원인 회원입니다." / 409 INVITATION_DUPLICATED "이미 초대한 회원입니다." 는 입력칸 아래 오류 문구 (모달은 열어 둔다) |
| 초대 모달 [취소] | 클릭, 바깥 클릭, Esc | 입력을 버리고 닫는다 |
| 초대 성공 | - | 답을 기다리는 초대 목록 다시 불러오기 |
| 초대 모달 [초대] | 429 INVITATION_RECENTLY_DECLINED | 입력칸 아래 "초대를 거절한 회원입니다. 거절한 때부터 24시간 뒤에 다시 초대할 수 있습니다." (D-121) |
| 답을 기다리는 초대 [취소] | 클릭 → 확인창 "{닉네임}님에게 보낸 초대를 취소할까요?" [닫기] [초대 취소] | POST /api/teams/{id}/invitations/{notificationId}/cancel → 목록 다시 그리기 + "초대를 취소했습니다." 안내 토스트. 404 면 "이미 답했거나 취소된 초대입니다." + 목록 다시 불러오기 |
| [이름 수정] | 클릭 | 같은 자리에서 팀 이름이 입력칸으로 바뀐다. 입력칸에 포커스 |
| [저장] | 클릭 또는 Enter | 입력 검사(빈 값, 20자 초과) → POST /api/teams/{id}/update → 읽기 보기로 돌아가고 좌측 네비 팀 이름도 바꾼다. "팀 이름을 바꿨습니다." 안내 토스트 |
| [취소] | 클릭 또는 Esc | 입력을 버리고 읽기 보기 |
| [⋮] | 클릭 | 행 메뉴 열기/닫기. 바깥 클릭 또는 Esc 로 닫는다 |
| 부관리자 지정 / 해제 | 클릭 | 확인창 없이 POST /api/teams/{id}/members/{userId}/role → 팀원 목록 다시 그리기. "부관리자로 지정했습니다." / "부관리자를 해제했습니다." 안내 토스트 |
| 관리자 넘기기 | 클릭 → 확인창 [넘기기] | POST /api/teams/{id}/owner → 팀 정보·팀원 목록 다시 그리기 (내 버튼은 부관리자 기준으로 바뀜). "관리자를 넘겼습니다." 안내 토스트 |
| 내보내기 | 클릭 → 확인창 [내보내기] | POST /api/teams/{id}/members/{userId}/remove → 팀원 목록·팀원 수 다시 그리기. "{닉네임}님을 내보냈습니다." 안내 토스트 |
| [팀 탈퇴] | 클릭 → 확인창 [탈퇴] | POST /api/teams/{id}/leave → 좌측 네비 팀 목록에서 빼고 /personal/tasks 로 이동. "팀에서 탈퇴했습니다." 안내 토스트 |
| [팀 해체] | 클릭 | 팀 해체 1단계 확인창 |
| 해체 1단계 [다음] | 클릭 | 2단계 확인창 |
| 해체 2단계 [삭제] | 클릭 | POST /api/teams/{id}/delete (입력한 팀 이름) → 좌측 네비 팀 목록에서 빼고 /personal/tasks 로 이동. "팀을 해체했습니다." 안내 토스트 |
| 확인창 | [취소], 바깥 클릭, Esc | 아무것도 하지 않고 닫는다 |
| 모든 API | 403 | "권한이 없습니다." 오류 토스트 + 팀 정보·팀원 목록 다시 불러오기 (다른 곳에서 역할이 바뀐 경우) |
| 모든 API | 404 | 대상이 팀원이면 "이미 팀에 없는 회원입니다." 오류 토스트 + 팀원 목록 다시 불러오기. 팀 자체가 없거나 내가 팀에 없으면 화면 열기의 404 처리 |
| 모든 API | 400 TEAM_NAME_MISMATCH | 2단계 확인창을 닫고 "팀 이름이 맞지 않습니다." 오류 토스트 (다른 곳에서 이름이 바뀐 경우) + 팀 정보 다시 불러오기 |
| 모든 API | 500 등 | 서버 오류 토스트 (overview.md 9) |
