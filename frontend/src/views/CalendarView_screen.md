# CalendarView_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/views/CalendarView.vue
- **화면 이름**: 캘린더
- **화면 목적**: 칸반 작업과 히스토리 작업을 기간에 맞춰 월간 캘린더에서 보고, 작업을 눌러 상세 내용을 본다 (보기 전용, D-014, D-015)
- **접근 URL**: /personal/calendar (개인 공간), /teams/{팀 id}/calendar (팀 공간, D-090). 같은 화면 파일을 쓰고 경로로 공간을 구분한다
- **접근 권한**: 회원 (개인 공간), 그 팀의 팀원 (팀 공간, 역할 상관없이)
- **시안 파일 경로**: 프로젝트/docs/mockups/calendar_view.html
- **참고자료**: docs/reference/캘린더 참고.png

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

### 라이브러리
- FullCalendar 월간 보기(dayGrid) (D-002). v7 패키지 구성은 구현 때 공식 문서로 확인한다 (D-088)
- 한국어, 일요일 시작, 월 보기 하나만 (주간·일간 보기 없음)

## 2. 레이아웃

공통 레이아웃(MainLayout)의 내용 영역 안에 카드 하나로 들어간다.

| 영역 | 위치 | 내용 |
|---|---|---|
| 머리 | 카드 맨 위 | 가운데: [‹] 년월 "2026.11" [오늘] [›] / 오른쪽: 색 안내 (대기·진행·완료·히스토리) (D-109) |
| 요일 줄 | 머리 아래 | 일 월 화 수 목 금 토 (일 빨강, 토 파랑) |
| 날짜 칸 | 나머지 | 6주 × 7일 (그 달이 5주면 5주). 칸마다 날짜 숫자, 공휴일 이름, 작업 막대 |
| 상세 모달 | 화면 가운데 (어두운 배경 위) | 누른 작업의 상세 (D-108) |
| 더보기 창 | 누른 "+N" 근처 | 그 날의 작업 전체 목록 (FullCalendar 기본 더보기 창) |
| 알림(토스트) | 화면 위쪽 가운데 | 오류 토스트 |

### 반응형 기준
- 내용 영역 최소 폭 320px 을 따른다 (MainLayout_screen.md). 날짜 칸은 7등분
- 576px 미만: 색 안내를 머리 아래 줄로 내리고, 막대 글자 11px, 칸마다 보이는 막대는 2줄까지 (넘치면 +N)
- 576px 이상: 칸마다 보이는 막대는 3줄까지 (넘치면 +N)

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| [‹] / [›] | 아이콘 버튼 (bi-chevron-left / bi-chevron-right) | 이전 달 / 다음 달 | - | aria-label "이전 달" / "다음 달" |
| 년월 | 제목 | 2026.11 | 보고 있는 달 | |
| [오늘] | 작은 버튼 (bi-arrow-counterclockwise) | 오늘 | - | 오늘이 있는 달을 보고 있으면 비활성 |
| 색 안내 | 색 점 + 글자 4개 | 대기 / 진행 / 완료 / 히스토리 | 고정 | |
| 요일 | 텍스트 | 일 ~ 토 | 고정 | 일 빨강, 토 파랑 |
| 날짜 숫자 | 텍스트 | 1 ~ 31 | - | 일요일·공휴일 빨강, 토요일 파랑, 다른 달 날짜는 흐리게 (색은 유지한 채 연하게) |
| 오늘 표시 | 원 | 오늘 날짜 숫자를 기본색 원 안에 흰 글자 | 브라우저 날짜 | 공휴일·주말이어도 원이 우선 |
| 공휴일 이름 | 작은 텍스트 | 현충일 등 | GET /api/holidays | 날짜 숫자 오른쪽, 빨강. 넘치면 … |
| 여러 날 작업 막대 | 막대 | 상태 연한 배경 + 제목 | GET /api/.../calendar | 기간 동안 이어진 가로 막대. 주가 바뀌면 다음 줄에서 이어진다. 제목은 넘치면 … |
| 하루 작업 | 줄 | 왼쪽 상태 색 세로 띠 + 제목 | GET /api/.../calendar | 시작일 = 종료일인 작업 |
| +N | 링크 | +2 등 | - | 칸에 다 못 보인 작업 수 |
| 상세 모달 | 모달 (D-108) | 상태 배지(히스토리면 "히스토리"), 제목, 기간, 작업자(팀 공간만, 없으면 "없음"), 내용(줄바꿈 그대로), [닫기] | 누른 CalendarTask | 보기 전용. 수정 내역·수정 버튼 없음 |

- 작업 순서: 시작일이 빠른 것 → 기간이 긴 것 → 작업 id 순 (서버 순서 그대로)
- 상태 색: 대기·진행·완료는 TaskView 상태 색과 같다. 히스토리는 따로 연한 회색 (D-106, 7. 디자인 값)
- 기간 표시는 TaskView 와 같다 (2026.11.10 ~ 2026.11.20 / 하루면 2026.11.10)

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 열기 | 들어옴 | 오늘이 있는 달을 보여준다. 보이는 기간(첫 칸 ~ 마지막 칸)으로 캘린더 API, 그 기간에 걸친 해(1~2개)로 GET /api/holidays 를 함께 부른다. 팀 공간에서 404 면 MainLayout 과 같은 처리 (팀 목록 새로고침 + /personal/tasks) |
| [‹] / [›] | 클릭 | 이전 / 다음 달로 바꾸고 그 달의 보이는 기간으로 다시 불러온다. 공휴일은 이미 불러온 해면 다시 부르지 않는다 |
| [오늘] | 클릭 | 오늘이 있는 달로 돌아간다 |
| 작업 막대 / 하루 작업 | 클릭 | 상세 모달 열기 |
| +N | 클릭 | 더보기 창에 그 날 작업 전체. 거기서 작업을 누르면 상세 모달 |
| 날짜 칸 | 클릭 | 아무 일도 없다 (D-109) |
| 상세 모달 | [닫기], X, 바깥 클릭, Esc | 닫는다 |
| 공휴일 | isAvailable false 또는 실패 | 공휴일 없이 보여준다. 토스트를 띄우지 않는다 (D-107) |
| 캘린더 API | 실패 (500 등) | 서버 오류 토스트. 날짜 칸은 빈 상태로 보여준다 |

- 팀 캘린더는 실시간 반영 대상이 아니다 (D-104). 달을 바꾸거나 화면을 다시 열면 새로 불러온다

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 날짜 칸은 보이고, 카드 오른쪽 위 머리 옆에 작은 스피너 |
| 기본 | 이번 달, 오늘 원 표시, 작업 막대 |
| 작업 없음 | 날짜 칸만 (따로 안내 문구 없음) |
| 여러 날 작업 | 주를 넘어가는 막대 (다음 줄에서 이어짐) |
| 많은 작업 | 칸마다 3줄(576px 미만 2줄) + "+N" |
| 공휴일 | 날짜 빨강 + 공휴일 이름 |
| 공휴일 정보 없음 | 공휴일 표시 없이 일요일 빨강·토요일 파랑만 |
| 히스토리 작업 | 연한 회색 막대 |
| 다른 달 보기 | [오늘] 활성, 오늘 원 없음 |
| 상세 모달 | 어두운 배경 + 가운데 모달 (히스토리 / 대기·진행·완료, 팀 공간이면 작업자 줄) |
| 더보기 창 | 그 날 작업 목록 |
| 오류 | 서버 오류 토스트 |
