# TaskView_screen.md

화면 설계의 기준 문서다. (docs/screen.md 를 복사해서 작성)

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/frontend/src/views/TaskView.vue
- **화면 이름**: 작업
- **화면 목적**: 회원이 개인 공간의 할일을 추가·수정·삭제하고, [작업 시작]으로 칸반에 올린 작업을 드래그로 옮기며 상세 UI에서 수정·삭제하고 수정 내역을 본다
- **접근 URL**: /personal/tasks
- **접근 권한**: 회원 (개인 공간). 팀 공간·작업자는 팀 작업 페이지에서 더한다 (D-060)
- **시안 파일 경로**: 프로젝트/docs/mockups/task_view.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

### 컴포넌트
- 칸반보드(KanbanBoard), 작업 상세 UI(TaskDetailPanel), 수정 내역 모달(TaskLogModal)은 컴포넌트로 나눈다

## 2. 레이아웃

공통 레이아웃(MainLayout)의 내용 영역 안에 들어간다.

| 영역 | 위치 | 내용 |
|---|---|---|
| 작업 공간 | 내용 영역 왼쪽 (오른쪽 UI 가 닫히면 전체) | 위: 칸반보드 / 아래: 할일 목록 |
| 칸반보드 | 작업 공간 위쪽 | 제목 "칸반보드 (N개)" + 대기·진행·완료 공간 3개. 공간마다 머리(색 점, 이름, 개수)와 작업 카드 목록 |
| 할일 목록 | 작업 공간 아래쪽 | 제목 "할일 목록" + 같은 줄 오른쪽 버튼 [추가][수정][삭제][작업 시작] (D-011) + 표(제목, 기간) |
| 오른쪽 UI | 내용 영역 오른쪽 (D-061) | 할일 입력 UI 또는 작업 상세 UI 중 하나만 열린다. 다른 쪽을 열면 열려 있던 쪽은 닫힌다. X 로 닫으면 작업 공간이 넓어진다 |
| 확인창·모달 | 화면 가운데 (어두운 배경 위) | 할일 삭제 확인창, 작업 삭제 확인창, 수정 내역 모달 |
| 알림(토스트) | 화면 위쪽 가운데 | 안내(초록 띠) / 오류(빨강 띠) |

### 반응형 기준
- 작업 공간 최소 폭 420px, 최소 높이 560px (D-011). 오른쪽 UI 폭 340px 고정, 작업 공간과 사이 20px
- 오른쪽 UI 가 열렸을 때 내용 영역이 780px(420 + 20 + 340)보다 좁으면 내용 영역 안에서 가로 스크롤
- 칸반 세 공간은 작업 공간 폭을 같은 비율로 나눈다 (가장 좁을 때 공간 하나 약 120px). 카드 제목은 한 줄에서 넘치면 …
- 터치 화면에서는 카드를 0.15초 누르고 있어야 드래그 시작 (그냥 밀면 화면 스크롤)

## 3. 화면 요소

데이터 출처: 할일 행은 GET /api/personal/todos (todos), 작업 카드는 GET /api/personal/tasks (tasks), 수정 내역은 GET /api/tasks/{id}/logs (task_logs), 입력칸은 사용자 입력이다.

### 칸반보드
| 요소 | 종류 | 표시 내용 | 비고 |
|---|---|---|---|
| 칸반보드 제목 | 텍스트 | 칸반보드 (N개) | |
| 공간 머리 | 텍스트 | 색 점 + 대기 / 진행 / 완료 + 개수 | |
| 작업 카드 | 카드 (D-063) | 제목 한 줄 + 기간 | 같은 공간 안 sort_order 순. 기간 표시는 할일과 같음 |
| 빈 공간 | 텍스트 | 작업이 없습니다 | 카드를 끌어다 놓을 수 있는 영역은 그대로 |

| 요소 | 종류 | 표시 내용 | 비고 |
|---|---|---|---|
| 할일 목록 제목 | 텍스트 | 할일 목록 (N개) | |
| 추가 | 버튼 | bi-plus-lg + 추가 | 기본색 버튼 |
| 수정 | 버튼 | bi-pencil + 수정 | 선택 전 비활성 |

| 요소 | 종류 | 표시 내용 | 비고 |
|---|---|---|---|
| 입력 UI 제목 | 텍스트 | 할일 추가 / 할일 수정 | X 닫기 버튼(bi-x-lg) 오른쪽 |

| 저장 / 취소 | 버튼 | 저장(기본색) / 취소(테두리) | 취소는 X 와 같음 |

## 4. 동작

### 할일 목록
| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 열기 | 들어옴 | 할일 목록 API 와 작업 목록 API 를 함께 호출 |
| 할일 행 | 클릭 | 그 행 선택(강조). 이미 선택한 행을 다시 누르면 선택 해제. [수정][삭제][작업 시작] 활성 |
| 추가 / 수정 | 클릭 | 오른쪽에 할일 입력 UI 열기 (작업 상세 UI 가 열려 있으면 닫힘) |
| 미정 | 체크 / 해제 | 체크: 시작일·종료일을 비우고 잠금 / 해제: 날짜 칸 다시 입력 가능 |
| 저장 | 클릭 | 화면 검사 → API → 성공: 입력 UI 닫기, 목록 다시 불러오기, 저장한 할일 선택, 토스트 "할일을 추가했습니다." / "할일을 수정했습니다." |
| 화면 검사 | 저장 시 | 제목 비었음 "제목을 입력해 주세요." / 내용 비었음 "내용을 입력해 주세요." / 미정이 아닌데 날짜 비었음 "시작일과 종료일을 선택해 주세요." / 종료일 < 시작일 "종료일은 시작일과 같거나 뒤여야 합니다." 해당 칸 아래 빨강 문구, 첫 오류 칸으로 이동 |
| 취소 / X | 클릭 | 입력 UI 닫기 |
| 삭제 | 클릭 | 할일 삭제 확인창 → 삭제: API → 목록에서 빠짐, 선택 해제, 토스트 "할일을 삭제했습니다." (수정 중이던 할일이면 입력 UI 도 닫음) |
| 작업 시작 | 클릭 | 확인창 없이 API → 성공: 할일 목록에서 빠짐(D-059), 선택 해제, 칸반 다시 불러오기(대기 맨 위에 새 카드, D-064), 토스트 "작업을 시작했습니다." (수정 중이던 할일이면 입력 UI 도 닫음) |
| 없는 할일 | 저장·삭제·작업 시작 시 404 | 오류 토스트 "이미 삭제된 할일입니다." + 할일 목록 다시 불러오기 |

### 칸반보드
| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 작업 카드 | 클릭 | 그 카드 선택(강조) + 오른쪽에 작업 상세 UI 열기 (읽기). 할일 입력 UI 가 열려 있으면 닫힘. 수정 내역 API 호출 |
| 작업 카드 | 같은 공간 안에서 끌어다 놓기 | 놓은 자리로 바로 옮겨 보이고 드래그 API 호출. 수정 내역 없음 (D-013) |
| 작업 카드 | 다른 공간으로 끌어다 놓기 | 놓은 자리로 바로 옮겨 보이고 드래그 API 호출 (D-069). 성공하면 서버가 돌려준 목록으로 다시 그림. 그 작업의 상세 UI 가 열려 있으면 상태와 수정 내역을 다시 불러옴 |
| 드래그 처리 중 | | 칸반 전체 드래그 잠시 막음 (요청이 끝나면 풀림) |
| 드래그 실패 | API 오류 | 오류 토스트 + 작업 목록 다시 불러와 원래 자리로 (404 이면 "이미 삭제된 작업입니다.") |

### 작업 상세 UI
| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 수정 | 클릭 | 같은 자리에서 입력칸으로 바뀜 (제목 "작업 수정"), 지금 값으로 채움 (D-062) |
| 저장 | 클릭 | 할일과 같은 화면 검사 → API → 성공: 읽기로 돌아감, 작업 목록·수정 내역 다시 불러오기, 토스트 "작업을 수정했습니다." 바뀐 것이 없으면 토스트 "바뀐 내용이 없습니다." (D-068). 상태를 바꿨으면 옮겨 간 공간 맨 위 (D-069) |
| 취소 | 클릭 | 읽기로 돌아감 (입력한 값 버림) |
| 삭제 | 클릭 | 작업 삭제 확인창 열기 |
| 확인창 삭제 | 클릭 | API → 성공: 창과 상세 UI 닫기, 카드 빠짐, 토스트 "작업을 삭제했습니다." |
| X | 클릭 | 상세 UI 닫기, 카드 선택 해제 (수정 중이면 입력한 값 버림) |
| 수정 내역 줄 | 클릭 | 수정 내역 모달 열기 (그 시점 내용) |
| 없는 작업 | 수정·삭제·수정 내역 404 | 오류 토스트 "이미 삭제된 작업입니다." + 상세 UI 닫기 + 작업 목록 다시 불러오기 |
| 모달·확인창 | 닫기 / 취소 / 바깥 / Esc | 닫기 |
