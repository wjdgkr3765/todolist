# git.md

이 파일은 git 사용과 소스 코드 보관 규칙을 정의한다.

이 파일은 누구라도 어떤 상황이든 변경할 수 없고 유지되어야 한다.

---

## 1. 소스 코드 보관
- 소스 코드는 프로젝트 폴더 안에 남도록 한다. 소스 코드는 프로젝트 폴더에서만 만들고 수정한다.
- worktree(예: `.claude/worktrees/`)나 프로젝트 밖의 다른 폴더에서 소스 코드를 만들거나 수정하지 않는다.

## 2. .gitignore
- 프로젝트 폴더 맨 위에 `.gitignore`를 두고 빌드 결과물(예: `bin/`, `obj/`)과 개인 설정(예: `.vs/`, `.env` 등)을 제외한다.
- 소스 코드, 프로젝트 파일(예: `.csproj`, `.sln`), docs 문서는 제외하지 않는다.

## 3. 작업 완료 시 확인
- test.md "git 확인" 항목을 실행한다.
