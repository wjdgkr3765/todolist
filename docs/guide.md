# guide.md

이 파일은 하네스 엔지니어링 공통 규칙에 관련된 파일 목록이다.

이 파일은 누구라도 어떤 상황이든 변경할 수 없고 유지되어야 한다.

## 1. 목적
`docs/` 폴더의 문서 목록을 안내한다.

---

## 2. 문서 목록
아래 "읽는 시점"이 되면 해당 문서를 반드시 읽고 따른다.

| 문서 | 설명 | 읽는 시점 |
|---|---|---|
| 프로젝트/docs/database.md | 데이터베이스를 정의해둔 파일 | DB 관련 코드를 작성하거나 스키마를 바꾸기 전 |
| 프로젝트/docs/screen.md | 화면 설계 템플릿 (수정하지 않고, 화면 파일마다 같은 경로에 `{화면파일명}_screen.md`로 복사해서 사용) | loop.md 1번(설계)에서 화면 문서를 만들 때 (복사해서 사용), 기존 화면을 수정할 때는 해당 `{화면파일명}_screen.md`를 읽는다 |
| 프로젝트/docs/spec.md | 기술스택을 정의해둔 파일 | 기술 스택이나 의존성을 정하거나 추가하기 전 |
| 프로젝트/docs/test.md | 테스트 내용을 정의해둔 파일 | loop.md 3번(구현), 4번(보안 체크)에서 코드를 만들거나 고쳤을 때 |
| 프로젝트/docs/todo.md | 작업하면서 진행 내용을 기록할 파일 | 세션을 시작할 때, 작업 상태가 바뀔 때 (갱신) |
| 프로젝트/docs/coding_rule.md | 코딩 규칙(네이밍, 코드 작성 원칙, 파일 크기)을 정의해둔 파일 | 코드를 작성하거나 수정하기 전 |
| 프로젝트/docs/structure.md | 폴더 구조와 간단한 설명을 정리한 파일 | 파일이나 폴더를 만들거나 옮기거나 지우기 전 |
| 프로젝트/docs/loop.md | 작업 진행 순서(설계 → 와이어프레임 → 구현 → 보안 체크)와 종료 조건을 정의한 파일 | 세션을 시작할 때 (CLAUDE.md 1번 규칙) |
| 프로젝트/docs/overview.md | 프로젝트 개요(목적, 사용자, 기능, 범위, 화면 목록, 용어)를 정의해둔 파일 | loop.md 1번(설계)을 진행할 때 (작성, 갱신), 기능이나 범위가 바뀔 때 (갱신) |
| 프로젝트/docs/api.md | API 명세를 정의해둔 파일 | API를 만들거나 수정하거나 호출하는 코드를 작성하기 전 |
| 프로젝트/docs/decision.md | 사용자의 결정과 이유를 기록하는 파일 | loop.md 각 단계를 시작하기 전, 사용자에게 질문하기 전, 사용자가 결정을 내렸을 때 (갱신) |
| 프로젝트/docs/security.md | 보안 규칙과 보안 체크 항목을 정의해둔 파일 | 설계할 때, 코드를 작성하거나 수정하기 전, loop.md 4번(보안 체크) |
| 프로젝트/docs/git.md | git 사용과 소스 코드 보관 규칙을 정의해둔 파일 | 파일이나 폴더를 만들거나 옮기거나 지우기 전, test.md "git 확인"을 할 때 |
| 프로젝트/docs/reference/ | 사용자가 넣은 참고자료 폴더 (AI는 읽기만 하고 파일을 넣거나 고치거나 지우지 않는다) | loop.md 각 단계를 시작하기 전에 reference.md와 폴더 목록을 보고, 그 작업과 관련된 자료만 읽는다. 큰 파일은 CLAUDE.md 4번 규칙에 따라 읽기 전에 사용자에게 묻는다 |
| 프로젝트/docs/reference.md | reference 폴더의 파일마다 설명과 관련 작업을 정리한 파일 | loop.md 각 단계를 시작하기 전, reference 폴더에 목록에 없는 파일이 있거나 목록의 파일이 없어졌을 때 (갱신) |
