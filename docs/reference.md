# reference.md

`docs/reference/` 폴더에 사용자가 넣은 참고자료 목록이다.

---

## 규칙

1. AI는 `docs/reference/` 폴더의 파일을 읽기만 한다. 파일을 넣거나 고치거나 지우지 않는다.
2. loop.md 각 단계를 시작하기 전에 폴더 목록을 보고, 아래 "자료 목록"에 없는 파일이 있으면 목록에 추가한다. 목록에 있는데 폴더에 없는 파일은 목록에서 지운다.
3. 그 작업과 관련된 자료만 읽는다. 큰 파일은 CLAUDE.md 4번 규칙에 따라 읽기 전에 사용자에게 묻는다.
4. `.gitkeep`은 빈 폴더를 git에 남기기 위한 파일이라 목록에 적지 않는다.
